# VigilScope Screenshot Guide

No fabricated screenshots are included. Contributors may add real screenshots
captured from a test system after removing usernames, paths, IP addresses,
command lines, notes, case content, and other sensitive data.

Suggested files:

- `overview-en.png`
- `overview-tr.png`
- `processes-en.png`
- `network-analysis-en.png`
- `detections-en.png`

Use the current dark theme, capture the complete application window, and state
the VigilScope version in the pull request that adds or updates screenshots.
